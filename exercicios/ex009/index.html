Listas Ordenadas

Para criar uma ordered list, vamos usar a tag OL para delimitar a lista e LI, list item para identificar cada item da lista.

  1. acordar
  2. ir ao banheiro
  3. escovar os dentes
  4. lavar o rosto
  5. secar o rosto
  6. voltar para o quarto
  7. guardar a escova

A tag OL possui um parâmetro type, onde configuramos o tipo de marcador da lista atual.

Você também pode indicar o início da contagem usabdo o parâmetro start.

Por exemplo, a tag ol type="I" start = "5" vai gerar itens numerados como V, VI etc...

Listas não Ordenadas

Para criar uma lista unordered list, vamso usar a tag ul para delimitar a lista e a tag li para criar cada item.

  • Pão
  • Leite
  • Tomate
  • Alface
  • Arroz
